Таблица 4.9 – Связи между таблицами
┌──────────────────────────────┬──────────────────────────────┬──────────────┐
│ Таблица 1                    │ Таблица 2                    │ Тип связи    │
├──────────────────────────────┼──────────────────────────────┼──────────────┤
│ country                      │ championship                 │ 1:N          │
│ championship                 │ match                        │ 1:N          │

│ match                        │ goal                         │ 1:N          │
│ person                       │ goal                         │ 1:N          │
│ goal_type                    │ goal                         │ 1:N          │
│ match                        │ player_squad                 │ 1:N          │
│ person                       │ player_squad                 │ 1:N          │
│ country                      │ player_squad                 │ 1:N          │
│ match                        │ coach_match                  │ 1:N          │
│ person                       │ coach_match                  │ 1:N          │
│ country                      │ coach_match                  │ 1:N          │
└──────────────────────────────┴──────────────────────────────┴──────────────┘
