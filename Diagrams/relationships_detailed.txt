1. COUNTRY ↔ CHAMPIONSHIP (Один ко многим - 1:N)

Описание:
  Одна страна может организовать много чемпионатов.
  Каждый чемпионат организуется ровно одной страной.

Реализация:
  - Таблица Championship содержит внешний ключ id_country
  - Класс Championship имеет навигационное свойство Country
  - Класс Country имеет навигационное свойство Championships (List<Championship>)

SQL связь:
  ALTER TABLE championship 
  ADD CONSTRAINT fk_championship_country 
  FOREIGN KEY (id_country) REFERENCES country(id_country);

Пример данных:
  Country: Россия (id=1)
    ├─ Championship: 2022 - Москва (id=1, id_country=1)
    └─ Championship: 2026 - Лос-Анджелес (id=2, id_country=1)

═══════════════════════════════════════════════════════════════════════════════

2. CHAMPIONSHIP ↔ MATCH (Один ко многим - 1:N)

Описание:
  Один чемпионат включает много матчей.
  Каждый матч принадлежит ровно одному чемпионату.

Реализация:
  - Таблица Match содержит внешний ключ championship_id
  - Класс Match имеет навигационное свойство Championship
  - Класс Championship имеет навигационное свойство Matches (List<Match>)

SQL связь:
  ALTER TABLE "match" 
  ADD CONSTRAINT fk_match_championship 
  FOREIGN KEY (championship_id) REFERENCES championship(id_championship);

Пример данных:
  Championship: 2022 - Москва (id=1)
    ├─ Match: Россия 2:1 Бразилия (id=1, championship_id=1)
    ├─ Match: Германия 1:1 Франция (id=2, championship_id=1)
    └─ Match: Испания 3:0 Англия (id=3, championship_id=1)

═══════════════════════════════════════════════════════════════════════════════
