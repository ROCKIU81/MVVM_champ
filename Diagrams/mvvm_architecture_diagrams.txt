ПОТОК ДАННЫХ В ПРИЛОЖЕНИИ

User Input (View)
       │
       ▼
Command Execution (ViewModel)
       │
       ├─ LoadCommand → LoadAsync() → Repository.GetAllAsync()
       │
       ├─ SaveCommand → SaveAsync() → CrudService.Save()
       │
       ├─ DeleteCommand → DeleteAsync() → CrudService.Delete()
       │
       └─ SearchCommand → ApplyFilter() → Filter ObservableCollection
       │
       ▼
Data Processing (ViewModel)
       │
       ├─ Update ObservableCollection
       │
       ├─ Notify PropertyChanged
       │
       └─ Update UI Bindings
       │
       ▼
Database Operations (Repository)
       │
       ├─ Query: SELECT * FROM table
       │
       ├─ Insert: INSERT INTO table VALUES (...)
       │
       ├─ Update: UPDATE table SET ... WHERE id = ...
       │
       └─ Delete: DELETE FROM table WHERE id = ...
       │
       ▼
PostgreSQL Database
       │
       ▼
Return Data to ViewModel
       │
       ▼
Update UI (View)
       │
       ▼
Display to User
