# World Cup MVVM

WPF-приложение для управления данными чемпионатов мира по футболу, разработанное с использованием паттерна MVVM.

## 📋 Описание проекта

Приложение предназначено для учёта и управления информацией о чемпионатах мира по футболу, включая страны-участницы, матчи, игроков, тренеров и забитые голы. Реализовано на платформе .NET 9 с использованием WPF и PostgreSQL.

## ✨ Основные возможности

### Управление данными
- **Страны** — добавление, редактирование и удаление стран-участниц
- **Чемпионаты** — управление чемпионатами (год, город, страна-организатор)
- **Матчи** — учёт матчей с указанием команд и счёта
- **Люди** — управление игроками и тренерами
- **Голы** — фиксация забитых голов (игрок, минута, тип)
- **Типы голов** — справочник типов голов (с игры, пенальти, автогол, головой)
- **Состав игроков** — формирование составов команд для матчей
- **Тренеры матчей** — назначение тренеров командам

### Статистика
- **Лучшие бомбардиры** — топ-15 игроков по количеству голов
- **Голы по типам** — распределение голов с процентами
- **Матчи по чемпионатам** — количество матчей и голов в каждом чемпионате
- **Таблица команд** — турнирная таблица с очками, победами/ничьими/поражениями, забитыми/пропущенными голами и разницей мячей

### Режимы работы
- **Тестовые данные** — 599+ записей загружаются в память без подключения к БД
- **Данные из БД** — работа с PostgreSQL через репозитории

## 🎨 Паттерны проектирования

В проекте реализовано **6 паттернов проектирования**:

1. **MVVM** — основная архитектура приложения
2. **Repository** — абстракция доступа к данным
3. **Dependency Injection** — инъекция зависимостей через конструкторы
4. **Command** — RelayCommand и AsyncRelayCommand для команд UI
5. **Service Layer** — бизнес-логика в отдельных сервисах
6. **Observer (INotifyPropertyChanged)** — уведомление об изменениях свойств

## 🚀 Запуск проекта

### Требования
- .NET 9 SDK
- Visual Studio 2022 или выше
- PostgreSQL (опционально, для работы с БД)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ROCKIU81/MVVM_champ.git
cd MVVM_champ
```

2. Откройте решение в Visual Studio:
```bash
MVVM_Champ.sln
```

3. Соберите проект:
```bash
dotnet build
```

4. Запустите приложение:
```bash
dotnet run --project MVVM_Champ
```

### Запуск тестов

```bash
dotnet test
```

## 📊 База данных

### Структура БД (8 таблиц)

- `country` — страны-участницы
- `championship` — чемпионаты мира
- `match` — матчи
- `person` — игроки и тренеры
- `goal` — забитые голы
- `goal_type` — типы голов
- `player_squad` — составы игроков
- `coach_match` — тренеры матчей

### Подключение к PostgreSQL

Настройте строку подключения в файле конфигурации или используйте режим "Тестовые данные" для работы без БД.
